01 / YOUR CATALOGUE

You define the targets.

Configure engines, models, supported efforts, and task descriptions. mroute selects from that catalogue, not an invisible list.

02 / VISIBLE DECISIONS

Review, then delegate.

Use route without launching an engine. Use explain and log to inspect decisions. Low confidence or classifier failure uses your configured safe target.

03 / LOCAL EXECUTION

No hosted prompt endpoint.

This site is documentation only. The default Jev classifier sends a bounded prompt preview to TypeSafe; choose heuristics for offline classification.

AUTHORIZED COLLABORATORS ONLY

Bring your own coding CLI.

These commands are not an anonymous quickstart. Private Go module installation requires repository access and authenticated Git access on your machine, with GOPRIVATE=github.com/alaborderie/f-0923-jev-model-router configured. Requires Go 1.27 or newer and an installed, authenticated claude, opencode, or codex CLI.

After initialization, review your targets in ~/.config/mroute/config.toml. Set TYPESAFE_API_KEY in your environment for Jev, or set classifier.backend = "heuristics" to classify offline.

go install github.com/alaborderie/f-0923-jev-model-router/cmd/mroute@latest
mroute init
# Review config and choose your classifier first
mroute doctor
mroute route "Explain this error"

Use it from your existing tools.

Claude Code and opencode integrations recommend or delegate separate tasks. They do not silently switch the model in an active session. Setup guides require private repository access.
