01 / YOUR CATALOGUE

You define the targets.

Configure engines, models, supported efforts, and task descriptions. mroute selects from that catalogue, not an invisible list.

02 / VISIBLE DECISIONS

Review, then delegate.

Use route without launching an engine. Use explain and log to inspect decisions. Low confidence or classifier failure uses your configured safe target.

03 / LOCAL EXECUTION

No hosted prompt endpoint.

This site is documentation only. Initialization selects offline heuristics when no TypeSafe key is set. With a key set, it selects Jev, which sends a bounded prompt preview to TypeSafe.

LOCAL INSTALLATION

Bring your own coding CLI.

Requires Go 1.27.1 or newer and an installed, authenticated claude, opencode, or codex CLI.

After initialization, review your targets in ~/.config/mroute/config.toml. Initialization chooses heuristics without a TypeSafe key and jev when one is present. Review the generated backend before routing. Existing configurations are never changed automatically.

go install github.com/alaborderie/jev-model-router/cmd/mroute@latest
mroute init
# Review config and choose your classifier first
mroute doctor
mroute route "Explain this error"

Inspect a route without a model request.

In a source checkout, use the committed offline catalogue. This classifies locally and records a decision; it does not execute the selected CLI.

mkdir -p .local-demo/mroute
cp eval/heuristics.toml .local-demo/mroute/config.toml
XDG_CONFIG_HOME="$PWD/.local-demo" XDG_STATE_HOME="$PWD/.local-demo" go run ./cmd/mroute route --json -- "Rename foo to bar"
XDG_CONFIG_HOME="$PWD/.local-demo" XDG_STATE_HOME="$PWD/.local-demo" go run ./cmd/mroute explain

The receipt includes target, effort, confidence, fallback reason and argv. The captured offline example records the catalogue and source revision. A recommendation is not proof of engine execution.

Privacy and scope

Heuristics classification does not contact a service. Jev classification sends a bounded prompt preview to TypeSafe. A separate engine run follows that CLI's own data handling. Local route logs record a prompt hash and routing metadata, not the prompt text. Review logs before sharing.

This is a separate-task launcher, not an automatic active-session model switcher. There is no hosted routing API, telemetry, account or waitlist on this page.

Use it from your existing tools.

Claude Code and opencode integrations recommend or delegate separate tasks. They do not silently switch the model in an active session. Setup guides are in the repository.
